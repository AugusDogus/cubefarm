An incremental game about growing an office into a corporation. Hire employees, improve workflows, and decide what the company becomes. Built with React and TypeScript. Progress saves locally in your browser.

## Develop

```sh
bun install
bun run dev
```

Run `bun test` for tests and `bun run build` for a production build.
